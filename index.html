🎮 Welcome
Azure Academy — AZ-900 Quest Trainer

This is a free, gamified study tool for the Microsoft AZ-900 (Azure Fundamentals) exam — daily quests, XP, loot, and a Learn section, instead of a plain flashcard deck.

What's inside:

  • 275+ quiz questions across Easy / Normal / Heroic difficulty, plus open-answer Lab exercises
  • A daily streak system, Mastery ranks, and a Loot Shop with collectible items
  • A Boss Fight to close out each day, and a Weak Spot Review mode for questions you've missed
  • A Learn section with short, bite-sized lessons (Beginner tier live, more levels coming)

Where this is headed: more Learn tiers (Intermediate/Advanced/Senior), richer visuals, and possibly other certifications down the line. It's a personal side project, actively evolving — expect some rough edges.

Your progress is saved only in this browser (no account, no server). Export a backup from Profile → Backup if you want a safety net.
